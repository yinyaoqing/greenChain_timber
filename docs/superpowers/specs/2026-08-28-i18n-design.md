# 全站 i18n（繁中 + 英文）設計文件

日期：2026-08-28
狀態：已核准（brainstorming 完成）

## 目標

為 greenChain_timber 前端（Next.js 16 App Router）建立完整的多語系機制，支援繁體中文（zh-TW，預設）與英文（en），全站涵蓋，語系反映在網址上。

## 決策

| 項目 | 決定 |
|---|---|
| 語言 | zh-TW（預設）、en |
| 範圍 | 前端全站（公開頁 + 登入後頁面）；後端 FastAPI 不動 |
| 路由策略 | 網址帶語系，`localePrefix: 'as-needed'`：`/dashboard` = 中文、`/en/dashboard` = 英文；現有中文連結不變 |
| 套件 | next-intl（App Router 原生支援 Server Components、內建 middleware 與 navigation 包裝） |

### 捨棄的替代方案

- **react-i18next**：App Router 的 Server Components 與 routing 都要自己接，工多且結果相同。
- **自製字典**：plural、格式化、locale 協商都要自己養，長期會退化成不完整的 next-intl。
- **Cookie 記語言、網址不變**：改動小但英文頁無法被搜尋引擎單獨收錄，不符合公開敘事頁的 SEO 需求。

## 架構

```
frontend/
  middleware.ts            # next-intl middleware：語系偵測/轉址（排除 _next、api、靜態檔）
  i18n/
    routing.ts             # defineRouting({ locales: ['zh-TW','en'], defaultLocale: 'zh-TW', localePrefix: 'as-needed' })
    request.ts             # getRequestConfig：依 locale 載入 messages
    navigation.ts          # createNavigation(routing) → Link, useRouter, usePathname, redirect
  messages/
    zh-TW.json             # 現有文案抽出，依 namespace 分區
    en.json                # 英文翻譯初稿
  app/
    layout.tsx             # 最小殼（或移除，由 [locale]/layout.tsx 承擔）
    [locale]/
      layout.tsx           # <html lang={locale}>、NextIntlClientProvider、generateMetadata
      page.tsx
      not-found.tsx
      dashboard/…
      draw/…
      login/…
```

## 文案規範

- Namespace 依頁面/元件分：`home`、`dashboard`、`draw`、`login`、`header`、`plotForm`、`plotDetail`、`drawPanel`、`map`、`carbonChart`、`statusBadge`、`common`。
- Server Components 用 `getTranslations`；Client Components 用 `useTranslations`。
- 內部連結一律改用 `i18n/navigation.ts` 匯出的 `Link` / `useRouter`，自動帶 locale。
- `metadata` 改為 `generateMetadata`，title/description 依 locale 輸出。
- Header 加語言切換器（zh-TW ⇄ EN），切換時保留當前路徑。

## 錯誤處理

- 缺 key：next-intl 開發模式警告並 fallback 顯示 key 路徑，不會 crash。
- 未支援語系路徑（如 `/ja/...`）：middleware 轉址至預設語系或 404。

## 驗收標準

1. `npm run build` 通過。
2. `/`、`/dashboard`、`/draw`、`/login`、404 頁在 zh-TW 與 `/en/...` 下各自正確顯示對應語言，手動走查。
3. 現有中文網址（無前綴）行為不變。
4. Header 語言切換器可在任一頁雙向切換且停留在同頁。
5. 全站無殘留硬編碼 UI 文案（grep 檢查元件內中文字串）。

## 範圍外

- 後端 FastAPI 錯誤訊息 i18n。
- 日文等第三語言（機制已可擴充：加 locale + messages 檔即可）。
- 使用者資料內容（地塊名稱等）翻譯。
