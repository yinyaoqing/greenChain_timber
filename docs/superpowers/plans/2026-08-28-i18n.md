# 全站 i18n（zh-TW / en, next-intl）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓前端全站支援 zh-TW（預設，無網址前綴）與 en（`/en/...`），文案集中於 messages JSON。

**Architecture:** next-intl + App Router `[locale]` 目錄；Next.js 16 的 middleware 改名 **proxy.ts**（功能相同）。`localePrefix: 'as-needed'`：中文網址不變、英文加 `/en` 前綴。所有內部連結/導向改用 next-intl 的 navigation 包裝以自動帶 locale。

**Tech Stack:** Next.js 16.3 (App Router, React 19), next-intl（最新版，需支援 Next 16）, Tailwind 4, TypeScript。

**Spec:** `docs/superpowers/specs/2026-08-28-i18n-design.md`

## Global Constraints

- locales：`['zh-TW', 'en']`，defaultLocale `'zh-TW'`，`localePrefix: 'as-needed'`。
- Next.js 16：middleware 檔名為 `proxy.ts`（不是 `middleware.ts`）。API/慣例可能與訓練資料不同，動手前先查 `frontend/node_modules/next/dist/docs/`。
- 工作目錄：所有指令在 `frontend/` 下執行（`npm`、`npx`）。
- 本專案無測試框架（package.json 無 test script）——驗證方式為 `npm run build` + `npm run lint` + grep 殘留中文；**不要**為此引入測試框架（YAGNI）。
- 內部導頁一律用 `@/i18n/navigation` 匯出的 `Link` / `useRouter` / `usePathname` / `redirect`；不得再從 `next/link`、`next/navigation` 拿這四者（`useSearchParams` 仍從 `next/navigation`）。
- 文案 key 全放 `messages/zh-TW.json` 與 `messages/en.json`，兩檔 key 結構必須一致。
- 每個 Task 結尾 commit；訊息用中文、conventional prefix（feat:/refactor:），並附 `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`。

**Interfaces:**

- [ ] **Step 1: 安裝 next-intl**

```bash
cd frontend && npm install next-intl
```

Expected: 安裝成功。若 peer dependency 與 next@16 衝突，先讀 `node_modules/next-intl` 的 README/錯誤訊息判斷該裝哪個版本線（next-intl 4.x 支援 Next 16），不要盲目 `--force`。

- [ ] **Step 2: 建立 `frontend/i18n/routing.ts`**

```ts
import { defineRouting } from "next-intl/routing";

export const routing = defineRouting({
  locales: ["zh-TW", "en"],
  defaultLocale: "zh-TW",
  localePrefix: "as-needed",
});
```

- [ ] **Step 3: 建立 `frontend/i18n/navigation.ts`**

```ts
import { createNavigation } from "next-intl/navigation";
import { routing } from "./routing";

export const { Link, redirect, usePathname, useRouter, getPathname } =
  createNavigation(routing);
```

- [ ] **Step 4: 建立 `frontend/i18n/request.ts`**

```ts
import { getRequestConfig } from "next-intl/server";
import { hasLocale } from "next-intl";
import { routing } from "./routing";

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested)
    ? requested
    : routing.defaultLocale;
  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  };
});
```

- [ ] **Step 5: 建立最小 messages 檔**

`frontend/messages/zh-TW.json`：

```json
{ "header": { "brand": "🌲 綠鏈林匯" } }
```

`frontend/messages/en.json`：

```json
{ "header": { "brand": "🌲 GreenChain Timber" } }
```

- [ ] **Step 6: 建立 `frontend/proxy.ts`**（Next 16 慣例，取代 middleware.ts）

```ts
import createMiddleware from "next-intl/middleware";
import { routing } from "./i18n/routing";

export default createMiddleware(routing);

export const config = {
  // 排除 api、Next 內部路徑與含副檔名的靜態檔
  matcher: "/((?!api|_next|_vercel|.*\\..*).*)",
};
```

若 next-intl 已提供 Next 16 專用匯出（如 `createProxy`），以 `node_modules/next-intl` 的型別/文件為準改用之；行為需求不變。

- [ ] **Step 7: 修改 `frontend/next.config.ts` 掛上 plugin**

現況檔案極小（預設 config）。改為：

```ts
import type { NextConfig } from "next";
import createNextIntlPlugin from "next-intl/plugin";

const withNextIntl = createNextIntlPlugin();

const nextConfig: NextConfig = {};

export default withNextIntl(nextConfig);
```

（`createNextIntlPlugin()` 預設尋找 `./i18n/request.ts`，路徑不同時明確傳入。）

```bash
cd frontend && npx tsc --noEmit
```

Expected: PASS（app 尚未搬遷，此時 build 全站仍是舊結構、proxy 不影響既有中文路徑）。

```ts
/** 數字顯示格式化（千分位；面積 2 位小數、碳匯 2 位小數） */
export function formatHa(v: number, locale: string): string {
  return `${v.toLocaleString(locale, { minimumFractionDigits: 2, maximumFractionDigits: 2 })} ha`;
}

/** template 例："{value} 噸 CO₂e/年" —— 由呼叫端以 t("format.co2ePerYear") 提供 */
export function formatCo2e(v: number, locale: string, template: string): string {
  return template.replace(
    "{value}",
    v.toLocaleString(locale, { maximumFractionDigits: 2 }),
  );
}
```

注意：next-intl 的 `t("format.co2ePerYear")` 對含 `{value}` 佔位的 message 直接呼叫會要求參數——呼叫端應改用 `t("co2ePerYear", { value: formatted })` 形式。因此更簡潔的等價實作（**採用這個**）：呼叫端直接寫

```tsx
tf("co2ePerYear", { value: v.toLocaleString(locale, { maximumFractionDigits: 2 }) })
```

並從 `format.ts` 刪除 `formatCo2e`（`formatHa(v, locale)` 保留）。兩處呼叫端（dashboard/page）依此寫法。
