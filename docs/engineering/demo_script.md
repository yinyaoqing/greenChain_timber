3. 備妥分頁：Amoy 合約頁 https://amoy.polygonscan.com/address/0x3fc1c4F56F7dc4A0b52Fd9B62dC1AEECdAce44F8

## 3 分鐘版（G1 快速走查：圈地 → 估算 → 上鏈 → 驗證）

| 時間 | 動作 | 講點 |
|---|---|---|
| 0:00–0:20 | Landing 頁 | 「台灣森林碳匯三大信任落差：量測不透明、重複申報、憑證可竄改——我們用一條流程解掉，讓企業的每一筆森林碳匯佐證都經得起檢驗、防得住漂綠質疑」 |
| 0:20–1:10 | 圈地申報：3D 地圖圈一塊 5–20 ha 林地（工具自動轉俯視），即時面積顯示 | 「衛星 + 3D 地形，聚合單位（公協會/產銷班）或企業專案管理者滑鼠圈出專案林地；面積即時計算，超出 0.1–1000 ha 直接擋」 |
| 1:10–1:50 | 填表（台灣杉/15 年/1500 株）送出 → 成功卡 + 6 年固碳曲線 | 「以環境部方法學架構與農業部係數為藍本之自動估算（現行係數為文獻示範參數，正式係數屬第二階段查證定稿），當年 + 未來 5 年；每筆估算綁公式版本可追溯」 |
| 1:50–2:30 | 儀表板 → 點入該林區詳情：飛行定位 + 綠色邊界 + 「上鏈處理中」動畫 → 轉 on_chain | 「送出當下已開始鑄造 NFT——不阻塞使用者，失敗自動重試。此為存證憑證，非經查證之碳權」 |
| 2:30–3:00 | 點 Tx Hash → Amoy 瀏覽器交易頁 | 「憑證不在我們手上，在公開區塊鏈上——任何人可獨立驗證」 |

## 8 分鐘版（加入防重疊、鏈上防偽、雜湊比對三個亮點）

前 3 分鐘同上，接著：

| 時間 | 動作 | 講點 |
|---|---|---|
| 3:00–4:30 | **重複申報防線一**：再圈一塊與剛才重疊的林地送出 → 地圖紅色高亮衝突區 + 衝突面積 | 「double counting 是碳權市場的道德風險核心——PostGIS 空間交集檢查，重疊 0.001 公頃就擋。（邊界說明：防重疊現僅涵蓋平台內申報範圍，尚未與國家登錄簿互通；第二階段將串接地籍圖資）」 |
| 4:30–5:30 | **防線二**：Amoy 合約頁 → Read Contract → `geoHashUsed` 貼入該林區 geoHash（詳情頁側欄可複製）→ 回傳 true | 「就算繞過我們的後端，鏈上合約本身拒絕同一幾何指紋二次鑄造」 |
| 5:30–7:00 | **可驗證性**：終端跑 `uv run python scripts/verify_hash.py` → 逐筆 MATCH | 「資料庫的邊界座標重算 SHA-256，與鏈上指紋完全一致——資料庫被竄改一個小數點都會 MISMATCH」 |
| 7:00–8:00 | 合約頁 `getPlotData(1)` 展示鏈上存的 geoHash/碳公斤數/樹種代碼；收尾 | 「鏈上只存指紋與噸數（省 gas、不洩地籍），原始資料留庫、隨時可比對——這就是 MRV 的 V」 |

## 風險備案

- Render 冷啟動：keepalive 已設；若仍遇到，開場先點一次儀表板讓它醒
- Amoy 測試網抖動：mint 卡住時說明重試機制（詳情頁停在處理中動畫即是活 demo），
  後台 `POST /api/admin/retry-pending` 可手動補鑄
- Mapbox 載入慢：先開好 /draw 分頁備用
