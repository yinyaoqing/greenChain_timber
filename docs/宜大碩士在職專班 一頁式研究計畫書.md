# 國立宜蘭大學碩士在職專班研究計畫書

### 專案名稱：基於環境倫理與數位 MRV 之全端森林碳權防偽與空間驗證平台開發

### 一、 研究動機與背景
隨著全球淨零碳排趨勢與台灣碳費制度之推行，自然碳匯已成為企業 ESG 轉型與減碳之剛性資產。然而，傳統森林碳權查驗（MRV）流程面臨三大核心倫理與技術痛點：查驗成本高、數據不透明、以及潛在之「重複申報與綠洗」道德風險。本研究立足於環境倫理學中之「分配正義」與「誠實性原則」，旨在利用現代資訊科技，將複雜之林業大數據與官方方法學數位代碼化，建構一個兼具社會信任與工程可行性之數位 MRV 平台。

### 二、 文獻回顧與競爭對手分析
1. **國際市場商轉先驅**：國際如 TraceX Technologies 已成功將數位 MRV 技術應用於土地管理與碳申報；歐洲之 ClimateTrade 與 senken 則利用區塊鏈技術建立去中心化之碳信用交易平台。
2. **台灣官方與民間現況**：農業部林業保育署近年推動「AIoT 森林碳匯估算系統」及與民間合作之「台灣林產品生產追溯系統（區塊鏈）」，並建置「自然碳匯與生物多樣性專案媒合平臺」。
3. **本專案之差異化與競爭優勢**：現有系統多偏向政府主導之大型科研計畫，使私有小林農難以跨入。本專案採純軟體與低成本之輕量級全端思維，聚焦於「空間幾何防重疊演算法」與「鏈上數位防偽標章（NFT）」，填補了台灣在「小林農去中心化聚合」與「極致透明度」上的技術斷層。

### 三、 系統架構與研究方法
1. **前端視覺化（Next.js + Mapbox GL JS）**：提供直觀之 3D 地形渲染網頁界面，供用戶繪製林區邊界多邊形（Polygon），並動態呈現未來 5 年之動態碳匯增量。
2. **後端演算法（Python FastAPI）**：以農業部公告之《造林碳匯專案方法學》為藍本建構估算引擎（係數採版本化管理，正式係數於研究期程內逐樹種查證定稿），實現自動化之碳匯估算。
3. **空間資料庫（PostgreSQL + PostGIS）**：利用 PostGIS 空間幾何欄位進行「空間重疊檢查（ST_Intersects）」，從根本杜絕一地多賣之欺詐行為。
4. **區塊鏈防偽層（Polygon 公鏈 + Solidity）**：將地理雜湊（geoHash）與碳噸數鑄造為不可篡改之資產憑證（NFT），並以鏈上幾何指紋唯一性檢查構成第二道防重複申報防線，實踐數位鋼印。

### 四、 預期貢獻
1. **學術價值**：將傳統林學公式轉譯為現代資通訊 API，並從科技倫理視角探討數位工具如何捍衛資訊正義。
2. **商業與社會貢獻**：以數位化流程取代人工實地量測與紙本審查（現行行政成本動輒數十萬元、耗時逾半年），預期將中小型造林專案之碳匯初期量測成本降低一個數量級——實際降幅將於研究期程內以在地個案實測驗證；並以對接台灣碳權交易所（TCX）規範為長期目標，為企業提供低綠洗風險之高品質本土碳資產。
