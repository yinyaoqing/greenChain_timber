# 經濟部小型企業創新研發計畫（SBIR）階段計畫書

## 一、 基本資料
*   **計畫名稱**：基於 Web3 與 GIS 空間防偽技術之自動化森林碳匯管理平台開發計畫
*   **申請類別**：先期研究（Phase 1）／個別申請（補助上限每案新臺幣 150 萬元、計畫期程 6 個月）
*   **技術領域**：民生化工與淨零碳排（智慧綠色科技）
*   **計畫期程**：2026年10月1日至2027年3月31日（共6個月）
*   **申請經費編列總額**：新台幣 3,000,000 元
    *   **申請政府補助款**：新台幣 1,500,000 元（50%，達先期研究個別申請補助上限）
    *   **企業自籌款**：新台幣 1,500,000 元（50%，以研發人員勞務人事費抵充）
*   **後續規劃**：本階段（先期研究）結案後，視實地導入成效銜接申請「研究開發（Phase 2）」（個別申請補助上限每年 600 萬元），進行多縣市規模化與正式碳權申請流程整合

## 二、 研發動機與痛點分析
台灣碳費制度已於 2025 年上路，2026 年 5 月大型排碳企業完成首次碳費申報繳納，對本土合規碳權之剛性需求達到歷史新高。然而，現行森林碳權市場面臨以下核心痛點：
1.  **查驗成本與門檻過高**：傳統森林碳權申請（MRV）極度仰賴人工實地量測與冗長審查，行政成本高達數十萬元且耗時逾半年，導致台灣大量小型私有林農（如宜蘭在地林地）被排擠於市場之外。
2.  **漂綠與重複申報風險**：缺乏公開透明之空間數據檢驗機制，大企業面臨「一地多賣（Double Counting）」之綠洗（Greenwashing）公關與法律風險。

本公司已以純軟體輕量架構自力完成「綠鏈林匯」數位 MRV（dMRV）平台之 **MVP 先期版本**並公開上線（原始碼與開發歷程完整公開於 GitHub，端到端驗收六案例全數通過），驗證了「圈地 → 空間防重疊 → 自動估算 → 區塊鏈存證」全流程之工程可行性。**本計畫申請之研發範疇為第二階段**：將先期 MVP 推進至可供真實林農與查驗場景使用之商轉版本，聚焦於官方方法學正式化、外部地籍交叉比對、實地數據校正與多角色查驗流程等尚未完成之關鍵研發。

## 三、 先期自研成果與本計畫技術創新性

**先期自研成果（已完成，不列入本計畫研發範疇，作為企業自籌研發能量之證明）**：
前後端分離之輕量化雲端 MVP 已公開上線——Next.js + Mapbox GL JS 3D 圈地圖台、FastAPI 估算引擎（以農業部《造林碳匯專案方法學》為藍本，係數版本化管理）、PostgreSQL + PostGIS 空間防重疊（ST_Intersects 即時同步攔截，重疊即回 HTTP 409 並回傳衝突區域）、Solidity 智慧合約部署於 Polygon 公鏈測試網（Amoy），經 Web3.py 混合架構將地理雜湊（geoHash）與碳噸數鑄造為 NFT 數位鋼印，鏈上 geoHash 唯一性檢查構成第二道防重複申報防線。端到端驗收（含防重疊負向案例、上鏈重試、鏈上雜湊比對）六案例全數通過。

**本計畫（第二階段）四大研發項目**：
1.  **官方方法學正式化（Methodology Formalization）**：先期引擎之樹種係數為文獻常見值示範參數；本計畫將逐樹種查證農業部最新公告之《造林碳匯專案方法學》正式係數並定稿，建立「係數版本化熱更換 + 查證出處紀錄」機制，使每筆估算可對應至官方文獻頁碼層級之可稽核依據。
2.  **外部地籍交叉比對（Cadastral Cross-Check）**：現有防重疊僅涵蓋系統內已申報林區；本計畫將串接內政部國土測繪圖資服務（地籍/國土利用調查圖層 API），於圈地當下同步交叉比對外部地籍界址與土地使用分區，將「一地多賣」防線自平台內延伸至全國地籍層級。
3.  **實地數據導入與模型校正（Field Calibration）**：新增樹木胸徑（DBH）輸入之異速生長（allometric）估算模式，並以合作單位（LOI）提供之實測林分數據校正生長模型參數，量化估算誤差區間。
4.  **多角色查驗流程與規模化（Verifier Workflow & Scale）**：新增林主／企業買方／查驗者三角色權限（RBAC）與查驗者稽核儀表板；空間防重疊演算法以萬筆級幾何資料進行壓力測試與索引調校（目標回應時間 < 500ms），達成商轉規模門檻。

## 四、 執行進度與經費編列大綱
1.  **第 1~2 個月**：完成三樹種官方方法學係數查證定稿與版本化熱更換機制；建立萬筆級測試幾何資料集，完成防重疊演算法壓力測試與空間索引調校（回應時間 < 500ms）。
2.  **第 3~4 個月**：完成內政部國土測繪圖資 API 串接與外部地籍交叉比對；實作胸徑（DBH）異速生長估算模式；依合作單位 LOI 導入實地林分數據進行模型校正。
3.  **第 5~6 個月**：完成三角色 RBAC 與查驗者稽核儀表板；全系統端到端整合測試（E2E）與正式環境驗收；取得至少 1 處在地私有林地、林業產銷班或環境信託組織之實地導入成果，完成第二階段結案。
4.  **經費編列**（總額 3,000,000 元，依先期研究補助上限滿額編列）：
    *   研究發展人員人事費 **2,100,000 元**（負責人全程投入及兼任研發人員；其中 1,500,000 元以自籌款人事費抵充）
    *   消耗性器材與原材料費 **350,000 元**（高階開發主機與雲端服務費用——Vercel／Render／Supabase 付費層與區塊鏈 RPC 節點服務）
    *   技術引進費 **400,000 元**（內政部地籍圖資介接授權與林業方法學顧問諮詢）
    *   國內差旅費 **150,000 元**（宜蘭／新竹實地林分數據採集與合作單位訪查）
